# Hey, I'm Manoj 

Final year BCA student from Bengaluru. Got into security after breaking into systems during an internship (legally, obviously) and finding it way more interesting than regular dev work.

## What I'm Working On

Right now I'm analyzing malware traffic captures to understand how infected machines talk to attacker servers. It's basically detective work but with network packets instead of fingerprints.

Also writing Python scripts to automate the boring parts of security analysis because manually running the same filters 50 times gets old fast.

## Stuff I Use

**Security:**
- Wireshark (spend too much time staring at packets)
- Nmap for network scanning
- Burp Suite when testing web apps
- Metasploit for exploitation stuff

**Development:**
- Python for automation and building tools
- Bash when I need quick scripts
- JavaScript/React when I want a proper interface

**Where I practice:**
- Kali Linux (main workspace)
- Ubuntu on WSL2 for dev work
- TryHackMe boxes when I have time

## Projects

**Malware Traffic Analysis** - Going through real malware PCAPs from the wild. Finding infected hosts, tracking command-and-control servers, pulling out IOCs. Started this to prove I can actually analyze threats, not just talk about tools.

**SIEM Log Analyzer** - Python tool that watches logs for attack patterns like SSH brute force, SQL injection attempts, privilege escalation. Maps everything to MITRE ATT&CK because that's how you actually communicate findings.

**PhishGuard** - Email security analyzer that checks for phishing/spoofing using SPF/DKIM/DMARC validation. Extracts IOCs and scores risk. Built it after getting annoyed at obvious phishing emails people still click.

**AnalystAI** - Data visualization tool where you ask questions in plain English and get charts. Made for a hackathon. Actually handles cases where it doesn't know something instead of making stuff up.

**Cryptography Toolkit** - Terminal app with SHA-256, AES-256, RSA-2048. Built this to actually understand how encryption works instead of treating it like magic.

## What I'm Learning

Getting better at log analysis and writing detection rules. Also improving Python scripting for security automation.

- Actually learned how attacks work instead of just theory
